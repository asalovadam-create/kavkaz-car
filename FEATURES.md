# Реализованные функции KAVKAZ-CAR (MVP)

## Клиент (без обязательной регистрации)

- Главная страница с реальными автомобилями сразу на экране
- Поисковая панель (город, марка/модель, бюджет, кузов)
- Каталог с фильтрами: город, кузов, цена, год, места, с/без водителя,
  для свадьбы, доставка, автомат, премиум
- SEO-страницы городов (`/grozny`, `/makhachkala`, ...)
- Карточка автомобиля: галерея, характеристики, условия аренды, о владельце,
  «другие автомобили этого владельца»
- Контакты владельца: звонок, WhatsApp, Telegram — без регистрации, с
  ненавязчивым дисклеймером об условиях аренды
- Избранное: локально для гостя (localStorage), синхронизация после входа
- Сравнение до 3 автомобилей
- «Помогите выбрать» — короткий опрос без ИИ (бюджет, событие, кол-во мест)
- Жалоба на объявление с указанием причины
- «Поделиться» с Open Graph превью (фото, модель, цена, город)
- Правила, политика конфиденциальности, пользовательское соглашение — в footer

## Владелец

- Регистрация и вход по телефону
- Пошаговый мастер добавления автомобиля (6 шагов: марка/модель → фото →
  условия → город → контакты → предпросмотр и публикация)
- Личный кабинет: автомобили, просмотры, обращения, статус тарифа
- Редактирование объявления, управление фотографиями (загрузка/удаление)
- «Подтвердить актуальность» — понижение доверия к объявлению без
  подтверждения (раздел 72 ТЗ)
- Поднятие объявления в выдаче (в рамках лимита тарифа)
- Профиль владельца / компании (BUSINESS)
- Страница тарифа с лимитами использования и активацией промокода

## Админка (отдельный вход и сессия)

- Обзорная статистика
- Пользователи: поиск, блокировка, ручная выдача тарифа
- Автомобили: смена статуса (published/paused/blocked/pending/draft/expired)
- Жалобы: скрыть / заблокировать / восстановить / отклонить
- Промокоды: генерация `KC-PRO-XXXX` / `KC-BUSINESS-XXXX`
- Журнал всех административных действий

## Безопасность (см. также `SECURITY_CHECKLIST.md`)

- Пароли — только хэш (scrypt через werkzeug)
- CSRF-токен на всех изменяющих запросах
- Rate limiting на login/register/admin-login/report/upload/promo
- Проверка загружаемых изображений по реальному содержимому, а не по расширению
- Security headers (CSP, HSTS, X-Content-Type-Options, Referrer-Policy, Permissions-Policy)
- Отдельная модель и сессия для администраторов, таймаут по неактивности
- Проверка владения ресурсом на каждом изменяющем запросе (защита от IDOR)
- Непредсказуемые публичные ID вместо последовательных числовых ID

## Осознанно НЕ реализовано в этой версии

Согласно ТЗ (раздел 119 и «Future features»), архитектура готова к расширению,
но следующее не входит в MVP:

- Онлайн-оплата подписки (сейчас — промокоды и ручная активация админом)
- Верификация документов, полноценное «проверено» (сейчас — только
  «телефон подтверждён» как честный минимум)
- Telegram-бот и push-уведомления (есть точки расширения в `services.py`/моделях)
- Онлайн-бронирование, залог, отзывы, рейтинг
- Геолокационный поиск «рядом» (только явные фильтры по городу)
- Сложный AI-подбор — «Помогите выбрать» работает на простой правило-based логике
